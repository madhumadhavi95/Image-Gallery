#Image Gallery

A modern and responsive Image Gallery website developed using HTML, CSS, and JavaScript. The project includes a colourful mixed-gradient background, image cards, search functionality, category filters, hover effects, dark mode, and a lightbox with next/previous image navigation.

Features

- 📸 Responsive image gallery
- 🔍 Search images
- 🏷️ Category filtering
- ✨ Hover effects
- 🌈 Colourful gradient background
- 🌙 Dark mode
- 🖼️ Full-screen image lightbox
- ⬅️➡️ Next and previous image navigation
- 📱 Mobile-friendly design

Technologies Used

- HTML
- CSS
- JavaScript
